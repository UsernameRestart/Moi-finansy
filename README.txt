# Мои финансы — версия 2
1. Распакуйте ZIP-архив.
2. Загрузите ВСЁ содержимое архива в корень GitHub-репозитория (index.html, manifest.json, service-worker.js и иконки).
3. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Откройте опубликованную HTTPS-ссылку в Safari и выберите Поделиться → На экран Домой.

Категории поступлений и расходов редактируются в приложении: Ещё → Мои категории.
Переименование переносит старые операции на новое название. При удалении категории её операции тоже удаляются — приложение попросит подтверждение.
Данные хранятся локально в браузере устройства. Сделайте резервную копию перед очисткой браузера или сменой устройства.
