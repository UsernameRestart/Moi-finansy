Как добавить на экран iPhone

  1. Открой приложение по ссылке в Safari.
  2. Нажми кнопку «Поделиться».
  3. Выбери «На экран Домой».
  4. Нажми «Добавить».

Чтобы установка на экран «Домой» работала как приложение, файл нужно разместить по защищённой HTTPS-ссылке. Этот HTML-файл — готовая версия приложения; после размещения открой его адрес в Safari.
